ATM Withdrawal Program

A simple JavaScript ATM withdrawal program that validates a withdrawal request before processing the transaction.

Features

The program checks four conditions:

* Invalid withdrawal amount — if the withdrawal is less than or equal to ₦0.
* Insufficient funds — if the withdrawal is greater than the available balance.
* Invalid denomination — if the withdrawal is not a multiple of ₦1,000.
* Successful withdrawal — if all conditions are satisfied.

Technologies Used

* JavaScript
